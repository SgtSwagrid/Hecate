AuthService

com.alecdorrington.hecate.server.AuthService
See theAuthService companion object
final class AuthService(users: UserStore, policy: AuthPolicy = ..., accounts: Option[AccountStore] = ..., wording: Option[String] => Wording = ...)

The implementation of the API endpoints specified in AuthApi, which register users, manage their cookie-based sign-in sessions, change and recover their passwords, and delete their accounts. Also resolves session tokens to users on behalf of every secured endpoint, this library's and the host application's alike.

Every refusal is worded for its reader: the language cookie each request carries is handed to wording, and the Wording that comes back writes the sentence. The library itself decides only why a request is refused.

Value parameters

accounts

The store that deletes accounts, or None to offer no account deletion. A host application should give one only once its own cascade can remove everything of its that belongs to a user; until then the endpoint is not served at all, and AuthRules.accountDeletion tells clients so.

policy

How long sessions last, and what makes a password acceptable.

users

The store the users, sessions and recovery codes are kept in.

wording

The wording refusals are written in, chosen by the language a request asks for, or None when it asks for none. Defaults to the library's English for every request.
