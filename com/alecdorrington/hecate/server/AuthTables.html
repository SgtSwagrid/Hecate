AuthTables

com.alecdorrington.hecate.server.AuthTables
final class AuthTables(val profile: JdbcProfile, prefix: String = ...)

The tables this library stores its users, sessions and groups in, defined against whichever JDBC profile the host application uses rather than a fixed one. Create an instance with the application's own profile and share it between the stores.

No table declares a composite primary key or a foreign key: Slick emits both as separate ALTER TABLE statements that no CREATE TABLE IF NOT EXISTS guards, so a second startup would replay and fail on them. Where a composite key would otherwise apply, the stores maintain uniqueness themselves.

Value parameters

prefix

Prepended to every table name, for applications that need this library's tables to sit in a namespace of their own.

profile

The Slick profile of the host application's database.

def createIfNotExists: DBIO[Unit]

Creates any of this library's tables that the database does not already have. Safe to run on every startup, and alongside the host application's own schema creation. There are no migrations: a table whose shape has changed since an older database was created is not altered, so such a database must be recreated.
